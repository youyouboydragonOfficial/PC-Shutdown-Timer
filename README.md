# ⏱️ PCシャットダウン予約ツール (PC Shutdown Timer)

Windows 向けの高機能・安全設計なシャットダウン予約ツールです。  
指定した時刻やタイマー（カウントダウン）により、パソコンのシャットダウン・再起動・スリープ・サインアウトを自動実行します。  
実行前には **事前通知ポップアップ機能** が作動し、作業中のデータ保存や延長・キャンセルの猶予を確実に確保します。

## 🌟 主な機能と特徴

### 1. 多彩な電源アクションに対応
- **⏻ シャットダウン** (`shutdown /s`)
- **🔄 再起動** (`shutdown /r`)
- **🌙 スリープ** (`PowrProf SetSuspendState`)
- **🚪 サインアウト** (`shutdown /l`)
- **強制終了オプション** (`/f`：未保存ファイルの確認をスキップして確実に実行)

### 2. 柔軟な予約モード
- **📅 指定時刻で予約**:
  - 日付選択（今日・明日など）＋ 時・分 指定
  - ワンクリック・クイック設定（+30分後、+1時間後、+2時間後、今夜23:00、深夜00:00など）
- **⏳ カウントダウンタイマーで予約**:
  - 指定時間・分・秒後に自動実行
  - クイックプリセット（15分、30分、45分、1時間、1時間30分、2時間）

### 3. 🔔 充実の事前通知機能（重要）
- シャットダウン実行前に警告音とともに最前面に警告ウィンドウを表示。
- 通知タイミングは自由に選択可能（1分前、3分前、5分前、10分前、15分前、30分前など）。
- 警告ウィンドウからワンクリックで **「10分延長」** や **「予約キャンセル」** が可能。
- 事前に「通知テスト表示」で実際の警告動作を確認可能。

### 4. リアルタイム・ステータス表示 & タスクトレイ格納
- 残り時間を大型デジタル表示（`01:29:45`）とスムーズなプログレスバーで視認可能。
- **タスクトレイ（通知領域）格納機能**:
  - 作業の邪魔にならないようトレイアイコンに最小化。
  - トレイアイコンのツールチップで残り時間をリアルタイム確認。
  - 右クリックメニューから「表示」「予約キャンセル」「終了」を操作可能。

### 5. 📦 しっかりとしたインストール版（インストーラー付属）
- Windows 標準のインストーラー形式（Inno Setup 製 `PCShutdownTimer_Setup_v1.0.0.exe`）。
- **ショートカット単体ではなく、アプリケーション本体・アンインストーラー (`unins000.exe`) を正規インストール**。
- Windowsの「設定 > アプリ > インストールされているアプリ」および「コントロール パネル」に正式登録され、不要になった際はクリーンにアンインストール可能。
- スタートメニューおよびデスクトップへのショートカット登録に対応。

## 📥 ダウンロードとインストール

1. [Releases ページ](https://github.com/youyouboydragonOfficial/PC-Shutdown-Timer/releases) から最新の `PCShutdownTimer_Setup_v1.0.0.exe` をダウンロードします。
2. ダウンロードしたインストーラーを実行します。
3. 画面の指示に従ってインストールを完了します（標準でユーザー領域に安全にインストールされるため、管理者パスワード不要で導入可能です）。
4. スタートメニューまたはデスクトップの「PCシャットダウン予約ツール」から起動します。

## 💻 開発・ビルド方法

### ソースコードからのビルド

```powershell
# リポジトリのクローン
git clone https://github.com/youyouboydragonOfficial/PC-Shutdown-Timer.git
cd PC-Shutdown-Timer

# ビルド
dotnet build -c Release

# 発行
dotnet publish -c Release -o publish_app

# インストーラーのビルド (Inno Setup 6 が必要です)
iscc installer.iss
```
